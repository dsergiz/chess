# Project instructions

## Summaries, brainstorms, and complex topics: Token Efficiency mode

When asked to summarize information, brainstorm ideas, or organize complex topics, prioritize
"Token Efficiency": produce a visual Mind Map in Mermaid.js syntax inside an Artifact instead of
long-form prose.

Rules:
1. Use `mindmap` or `graph TD` syntax in Mermaid.
2. Keep node labels extremely concise (1-3 words).
3. Only use detailed text if explicitly asked for "detailed explanations."
4. If the topic is too large for one map, provide a high-level overview map first.
5. The goal is to minimize output tokens while maximizing structural clarity.
